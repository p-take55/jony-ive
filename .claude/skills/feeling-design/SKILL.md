# feeling-design — 感情の的を、対話で見つけてから逆算する

デザインの良さは、ある瞬間に人がどう感じたかに宿る。形を考える前に「その体験を前にしたとき、どんな感情を引き起こしたいか」「それは何の瞬間に似ているか」を、**ユーザーと一緒に、対話で**見つける。

これは一人で答えを出して提出する作業ではない。感情の的は、ユーザーとの往復で彫り出す。そして単なるヒアリングでもない。**こちらから候補を提案し、相手が反応・却下・修正することで、二人で的を絞る。**

## やってはいけないこと（最重要）

- 感情の的がユーザーと**合意できる前に**、レイアウト・ワイヤーフレーム・UI・配色・コンポーネントを出さない。形は最後。
- 候補や質問を一度に丸投げしない。**1 手 = 数個の候補 ＋ 1 つの問い**、出したら相手の番。
- 一度の返信で完結させない。**最初の返信は「デザイン」ではなく「会話の口火」。** 提案と問いで終え、自分のターンを閉じて待つ。

## 盛らない（このスキル最大の落とし穴）

候補も到達点も、**盛った瞬間に死ぬ**。一番やりがちなのは、深そうな比喩や身体感覚の作文を並べること。それは真実の代わりに置いた飾りで、たいてい嘘になる。

候補を出す前に、必ず自分に当てる検品:

- **その人、その瞬間にほんまにそれ感じる？ 盛ってへん？**
- それ、**別のどんなプロダクトにも貼れる**作文ちゃう？（貼れるなら何も言っていない）
- 比喩を使うなら、真実を**正確に**運んでる？ 深そうだから置いただけちゃう？

そのために**接地を先にやる**: 候補を出す前に、その人がその瞬間に**実際なにをしていて、何が懸かっているか**を一行で押さえる。そこから外れた感情は、どれだけ美しくても捨てる。

**地味でも本当の感情**を選ぶ。盛った美しい感情より、地味で正確な感情の方が、ずっと強く形を導く。比喩や感覚描写は禁止ではない — 真実を正確に運ぶときだけ使う。

## 進め方

### 第 1 幕: 感情の的を、一緒に見つける（ここが本体）

「接地 → 候補を提案 → 反応を受けて絞る」を数往復。

1. **接地** — その瞬間に何をしていて何が懸かっているかを掴む。
2. **候補を提案** — 接地した現実に根ざした感情の的を 3 個前後、地味でいいから本当のものを出す。「どれが近い？ 混ざりでもいい。全部ハズレなら一言で」と渡す。
3. **絞る** — 相手の言葉の手がかりを拾い、次の提案を更新する。

提案する理由: 「どんな感情にしたい？」と裸で聞かれても人は答えにくい。具体的な候補があると「それは違う、こっち」と的確に反応できる。**提案は相手の輪郭を引き出す道具**で、押し付けではない。却下されたら喜んで捨てる。

抜ける条件: 「この感情・この瞬間だ」と相手と合意できたとき。

### 第 2 幕: 到達点を言語化して、合意する

見つけた感情を、その瞬間が成立しているときの感じとして書く。**一人称・現在形・具体。盛らず、実際に起きることだけ**。詩にしない。

評価語は禁句 — 「直感的」「心地よい」「モダン」「シンプル」「美しい」「使いやすい」。感情でなく評価で、形を導けない。出たら「で、具体的に何が起きてる？」に開く。

書いたら映し返す:「つまり、こういう感じ？」。違えば直す。合意できたら譲れない感情の質を **2〜4 個**に絞る（これも相手と確認）。これが北極星になる。

### 第 3 幕: 逆算して形にする（合意の後だけ）

合意した各「質」から、それを生む具体を導く — 間・動き・コピー・素材感・配置・密度。ここでも確定させず、提案して反応を見ながら降ろす。

**引き算**: 各要素に「どの質に効くか」を問う。どの質にも効かない要素は、無難でも削る。残ったものだけが意図になる。

## 例: 「盛り」と「接地」の違い（動きの見本。お題ごとに毎回ゼロから接地する）

下は方法の手本であって、流用する答えではない。お題が何であれ、その都度その瞬間を接地し直す。

ある「下書きを削除する確認ダイアログ」を例に取ると —

- **✗ 盛った候補**:「レバーを引くような厳粛な決断の瞬間」← 深そうだが、下書きを消す人はそんな重さを感じない。どんな delete にも貼れる作文。
- **✓ 接地して本当の候補**: 接地 =「間違って大事なものを消したくはない、でも毎回確認でせき止められるのもうっとうしい」→ 候補:「一回でスッと消えて、でも"今のなら戻せる"と分かっている軽さ」。

違いは、深さではなく**その瞬間の現実に当たっているか**。

## 心構え

- これは納品物ではなく会話。最初の一手は、接地した上での問いと提案。
- **カッコいい言葉より、本当の言葉。** 地味でも正確な感情が、美しいが嘘の感情より強く形を導く。
- 提案は相手を動かす道具。却下は前進。
- 形は最後。感情の合意より先に UI を描いたら、順序を間違えている。
